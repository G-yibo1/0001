# 港硕回忆录

一款以香港求学生活为背景的像素叙事网页游戏。使用原生 HTML、CSS 和 JavaScript，无需安装依赖或执行构建。

## 运行

直接打开 `index.html`，或在目录中启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

- `index.html`：游戏主入口
- `游戏浏览.html`：素材浏览与游戏入口
- `assets/`：场景、人物、剧情、样式与脚本资源

## 操作

- **移动**：WASD 或方向键，也可点击地面前往
- **奔跑**：Shift
- **互动**：F 或场景互动按钮
- **背包**：E
- **任务**：J
- **手账**：L
- **地图**：M
- **关闭界面**：Esc

## 已实现内容

- 角色创建、服装与配饰、导师引导、宿舍出生点
- 全港与区域地图、全屏街道及室内场景
- 四方向行走、腿部动画、12 位自主巡游 NPC
- 红茶冰室、海港城、电信诈骗三条完整事件
- 背包、任务、手账、快捷栏与事件进度记录

大型不透明场景图使用 WebP，人物透明素材保留 PNG。
