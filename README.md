# 港硕回忆录

一款以香港求学生活为背景的像素叙事网页游戏。使用原生 HTML、CSS 和 JavaScript，无需安装依赖或执行构建。

## 运行

直接打开 `index.html`，或在目录中启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

- `index.html`：游戏主入口（开场 + 街道）
- `intro/`：开场章节（加载动画、主菜单、创建形象、导师对话、选择宿舍）
- `游戏浏览.html`：素材浏览与游戏入口
- `assets/`：场景、人物、剧情、样式与脚本资源

## 操作

- **移动**：街道 A/D 或 ←/→；室内 WASD
- **奔跑**：Shift
- **互动**：F 或场景互动按钮
- **背包**：E
- **任务**：J
- **手账**：L
- **地图**：M
- **关闭界面**：Esc

## 开局流程

打开页面先进入 `intro/` 的开场：加载动画 → 主菜单 → 创建形象（姓名、形象）→ 办公室与 Mr.马 对话 → 选择宿舍。**在最后一页点击屏幕**即进入街道，开场中填写的姓名与性别会带进游戏。

同一标签页内刷新不会重播开场；想再看一次，新开一个标签页即可。
