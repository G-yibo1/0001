## 二、按条目的改动明细

### 1. 街道取消 W/S，室内保留 WASD

- 街道只响应 `A/D` 与 `←/→`，去掉上下移动，避免人物忽高忽低。
- 室内（红茶冰室等）继续 `WASD` 四向行走，`F` 互动。
- 快捷提示文案同步区分为「室外 A/D 移动；室内 WASD 移动」。

### 2. 人物站位高度统一

- 主角 `PLAYER_LIFT = 7.5`，NPC `NPC_LIFT = 7`，按百分比把所有人抬到人行道地面高度。
- 之前尝试的「上移 + 花坛前景遮挡」已回退，只保留上移半个身高。

### 3. NPC 尺寸 = 主角的 95%

```css
.street-npc{
  width:clamp(47.5px,4.94vw,72px);
  height:clamp(78px,14.25vh,120px);
}
```

### 4. 红茶冰室按旧版布局重排人物

- 只参考旧项目截图里的**人物布局与婆婆坐姿**，室内移动、碰撞、对话逻辑全部保持原样。
- 15 位角色：厨师、服务员、卡座客人、圆桌客人、柜台店员、柜台点单客人，婆婆改为坐姿。

### 5. 红茶餐廳 / 海港城改为「招牌高亮 + 感叹号」触发

- 不再是漂浮在空中的感叹号，而是走到建筑前时：**招牌边缘呼吸高亮** → 招牌上方出现 `!` → 按 `F` 进入室内。
- 电信诈骗来电的触发条件与表现**保持原样**（仍是浮动感叹号 + 走近自动来电）。

### 6. 高亮框与招牌像素级对齐

- 招牌位置改为记录**背景图里的真实像素矩形**，渲染时按 `object-fit:cover` 的缩放与上下裁切反算：

| 招牌 | 背景图 | 像素矩形 (x, y, w, h) |
|---|---|---|
| 紅茶餐廳 | `02.webp` | 392, 360, 188, 53 |
| HARBOUR CITY 海港城 | `04.webp` | 526, 317, 264, 54 |

- `.sign-glow` 加 `box-sizing:border-box`，描边画在框内，不会比招牌大 4px。
- `!` 徽标改用专用关键帧 `sign-alert-bob`，避免动画 `transform` 覆盖居中偏移。
